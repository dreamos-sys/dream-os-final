️ Security Framework

  • AES-256-GCM Encryption - Enkripsi militer untuk semua data sensitif
  • Device Fingerprinting - Identifikasi unik perangkat dengan hash SHA-256
  • Single Device Lock - Mencegah login ganda di perangkat berbeda
  • Session Management - Auto-logout 2 menit idle dengan warning 30 detik
  • Audit Trail - Pencatatan semua aktivitas sistem (kecuali dev mode)
  • Rate Limiting - Maksimal 5 percobaan login, lock 15 menit
  • Anti-Screenshot - Deteksi & blur screen saat screenshot terdeteksi
  • Row-Level Security - Database protection dengan Supabase RLS
