🔐 Pemberitahuan Keamanan & Privasi
Dream OS menggunakan teknologi Device Fingerprinting dan Enkripsi AES-256 untuk:
  • Mencegah login ganda di perangkat berbeda
  • Melindungi data sensitif Anda
  • Mencatat audit trail untuk keamanan
  • Memastikan kepatuhan ISO 27001 & UU PDP

Data yang dikumpulkan: Device ID (hash), timestamp login, aktivitas sistem.
Data TIDAK dijual dan dihapus otomatis saat logout.

Kebijakan Privasi & Keamanan

1. Pengumpulan Data

Kami mengumpulkan data berikut untuk keamanan sistem:

  • Device Fingerprint: Hash unik perangkat (User Agent, Screen Resolution, Timezone)
  • Login Activity: Timestamp, IP address (jika tersedia), role pengguna
  • Audit Trail: Semua aksi penting (login, logout, akses modul, perubahan data)
  • Session Data: Token sesi yang dienkripsi dengan AES-256-GCM

2. Tujuan Penggunaan

  • Single Device Lock: Mencegah satu akun login di 2 perangkat berbeda
  • Security Audit: Melacak aktivitas mencurigakan
  • Compliance: Memenuhi standar ISO 27001 & UU Perlindungan Data Pribadi
  • Session Management: Auto-logout setelah 2 menit idle

3. Perlindungan Data

  • Enkripsi: AES-256-GCM untuk semua data sensitif
  • Hashing: SHA-256 untuk password & device fingerprint
  • Secure Storage: LocalStorage dengan encoding Base64 + encryption
  • Auto-Clear: Data sesi dihapus saat logout atau timeout

4. Hak Anda

  • ✅ Hak akses: Melihat data yang kami simpan
  • ✅ Hak penghapusan: Data dihapus otomatis saat logout
  • ✅ Hak penarikan consent: Dapat menolak, namun fitur keamanan akan terbatas
  • ✅ Hak portabilitas: Export data dalam format JSON

5. Kepatuhan Hukum

Sistem ini mematuhi:

  • 🇮🇩 UU No. 27 Tahun 2022 tentang Perlindungan Data Pribadi
  • 🌍 ISO 27001 - Information Security Management
  • 🔐 ISO 9001 - Quality Management
  • WCAG 2.2 AA - Accessibility Standards
